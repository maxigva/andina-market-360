# Perfil público orientado a proyectos (borrador)

## Sobre mí
Estudiante de Git y GitHub. Trabajo con datos **ficticios** para practicar control de versiones, pruebas y publicación.

## Proyecto destacado: Andina Market 360
- **Caso:** cadena ficticia con sedes en Lima, Ica y Arequipa.
- **Objetivo:** convertir `data/ventas.csv` (12 ventas simuladas) en totales por sede, por producto y por mes.
- **Resultado verificable:** 12 operaciones y S/ 1845.00, calculados por `src/resumen.py` y comprobados con pruebas `unittest`.

## Objetivos
1. Mantener un historial de commits claro y en español.
2. Revisar cada cambio con pull requests.
3. Publicar resultados calculados, nunca escritos a mano.

## Tecnologías
Git · GitHub · Python 3 (biblioteca estándar) · HTML/JavaScript · GitHub Actions

## Protección de datos y compromiso ético
- Todos los datos de los proyectos son simulados; no hay personas ni ventas reales.
- No publico contraseñas, tokens, claves ni correos personales.
- Si detecto un dato sensible en un commit, lo reporto y lo retiro siguiendo el procedimiento de seguridad del repositorio.
- Cito las fuentes y respeto las licencias del material de terceros.
